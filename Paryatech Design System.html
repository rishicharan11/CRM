ParyatechOS Design System

Every value on this page is taken from the two finalized modules, not invented. The page renders itself in its own tokens — what you see is the system describing itself. Where a framework default disagrees with the module, the module wins.

The one rule

A component may only read Tier 3. Tier 3 may only read Tier 2. Tier 2 may only read Tier 1. Never put a raw hex in a component. Break that chain and theming dies.

Column budget

The single most common failure in this platform. Fixed tracks plus text-column floors must total less than the container, or columns collide.

Budget before you build

A booking detail table has roughly 582px. Six columns is the ceiling. If you need a seventh value, fold it under an existing one as a second line — never add a track. That is the fix that worked every time; re-tuning widths never did.
